# Portfolio - Henrique Pella

Base estática do portfólio criada em HTML/CSS/JS.

## Como usar
- Abra `index.html` no navegador para ver a versão local.
- Edite o conteúdo nas seções: `Sobre`, `Experiência`, `Projetos`, `Habilidades` e `Contato`.

## Estrutura
- `index.html` — página principal
- `styles/styles.css` — estilos
- `scripts/scripts.js` — scripts leves
- `assets/profile.svg` — avatar (substitua pela sua foto)

## Próximos passos sugeridos
- Preencher conteúdo com os dados reais do currículo (texto, datas, links e foto).
- Atualizar `mailto:` e links do GitHub/LinkedIn em `index.html`.
- (Opcional) Fazer deploy no GitHub Pages: crie um repositório e habilite Pages apontando para a branch `main`.
